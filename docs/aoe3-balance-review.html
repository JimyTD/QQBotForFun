一、口径说明：这份报告怎么算「强 / 弱」

平衡改动的原始数据只是一堆字段差异（attack_ranged: 36 → 34）。要判断强弱，必须先把字段差异 换算到可比较的量纲上。本报告同时用三套口径，互不替代：

① 静态战力分（有幅度）

复用斗蛐蛐黑名单乱斗配兵用的 lineup.power_score： √(HP_eff × DPS_eff)，其中 HP 含护甲轻微增益，DPS 对单击伤害与射速各做一次 sqrt 溢出减益。

能答：改完值不值得多派两个。不能答：抬手、射程、克制倍率、伤害类型、溅射池的改动它看不见。

② 归因分解（说清来源）

在 ln 空间把总变化拆成 生命值 / 单击伤害 / AOE / 射速 四份贡献（数值差分，各项可加和到 100%）。

能答：变强是「血厚了」还是「输出快了」。不能答：非线性阈值效应（例如伤害刚好越过对手血线）。

③ 模拟器实证（看真实结果）

新版 10 个 vs 旧版 10 个的镜像对战，每单位 40 场，双向交换红蓝消除阵营偏差； 另有对四类固定陪练（火枪兵 / 轻骑兵 / 弩手 / 鹰炮）各 20 场的胜率迁移。

能答：所有字段综合起来，实战到底谁赢。不能答：幅度。对冲战斗有滚雪球效应， 4% 的血量优势也可能被放大成 90% 胜率，所以胜率只能当方向信号，不当强弱倍数。

复现：uv run python scripts/aoe3_balance_review.py → uv run python scripts/aoe3_balance_report.py。

三、口径分歧：公式与实战打架的单位

这是本次更新最值得看的一类改动 —— 战力分几乎没动，实战却天翻地覆。共同原因有三：

  • 伤害类型 / 护甲类型：静态公式只取 max(近战护甲, 远程护甲)，而攻城护甲、 伤害类型（Hand / Ranged / Siege）只在“打特定护甲”时才生效。新增 armor_siege 的单位会表现为“内战大赢、对外不变”。
  • 类型标签（type）：标签是克制倍率的匹配键。删掉 AbstractHandCavalry 这类标签，会让所有“克制手骑兵”的单位失去加成 —— 战力公式看不见，实战里却等于被全场克制。
  • 代表动作 / 槽位增删：公式只算“有没有攻击”，不算“用哪个槽”。近战槽消失的单位若本来靠远程输出， 公式会扣分而实战毫无变化。

九、这版更新对斗蛐蛐意味着什么

1. 池子变大，强弱跨度变大

新增 65 个单位，其中一批是「原住民 / 佣兵 / 革命兵」系列。押注池与单挑池同步扩容， 抽到极端单位的概率上升，配兵的战力锚点也更分散。

2. 手感类改动集中在抬手与射程

本次最容易被忽略的是 windups 与 range_min / range_melee 的变化： 它们在战力公式里权重为零，但在对冲战斗里直接决定谁先出手。

3. 攻城护甲与伤害类型成为暗线

投石索兵、里尔火炮等新增 armor_siege，只影响「被攻城伤害打」的场合。 这类改动在混编阵容里会被放大，在单兵镜像里则表现为内战大赢、对外不变。
