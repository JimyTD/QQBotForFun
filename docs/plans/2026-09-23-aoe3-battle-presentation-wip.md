## 第一阶段：线上问题盘点

### P0：已经在正式群局暴露

#### P0-1 回放视频可能完全没有输出

**表现**

- 正式群局结束后，只看到文字战报，没有视频。

**已确认的历史原因**

- 第一次上线时，旧帧协议没有 `radius`，录制器把它保留为 `None`，视频渲染器执行 `float(None)` 崩溃。
- 第二次上线时，视频文件传给 NapCat 的是 bot 容器本地路径，NapCat 无法访问，返回 `ENOENT`。

**当前状态**

- 两处均已修复并部署。
- 仍需在群内持续观察，确认不是只对个别对局有效。

#### P0-2 网页兵种 icon 完全不显示

**表现**

- 网页长期只有红蓝圆点，没有兵种图标。

**已确认原因**

- `<datalist id="unit-options">` 定义在 `<script>` 之后。
- `bootstrapCatalog()` 执行 `unitOptions.innerHTML = ""` 时元素还是 `null`，抛出异常并被 `catch` 吞掉。
- 兵种目录和 `state.unitIcons` 初始化都未完成，绘制始终回退到圆点。

**当前状态**

- 已修复，网页图标可以正常显示。

#### P0-3 网页图标尺寸不合适

**表现**

- 第一次修好后，图标比碰撞体大一圈。
- 改成完全同径后，普通步兵又偏小，几乎看不清。

**当前状态**

- 已改为接近碰撞体大小并保留最小可读尺寸。
- 仍需在网页和不同规模对局里继续观察。

### P1：已确认存在，当前实现状态

#### P1-1 HP 环是未确认加入的表现

**表现**

- 视频和网页都有单位 HP 环。

**问题**

- HP 环不在已确认的视觉方案里。
- 用户明确表示旧的“受伤变暗”逻辑更好。

**处理方向**

- 去掉 HP 环。
- 恢复受伤后整体变暗。

**当前状态**

- 已完成：视频与网页均移除 HP 环，恢复按 HP 比例整体变暗。

#### P1-2 视频 HUD 的兵种构成会静默丢失

**表现**

- 视频 HUD 只显示前四种兵种。
- 第五种及之后的兵种被丢弃，没有提示。

**原因**

- 渲染器使用 `parts[:4]`，属于实现中自行加入的裁剪。

**处理方向**

- 超过四种时显示 `等 N 种`，不能静默省略。

**当前状态**

- 已完成：超过四种时显示 `等 N 种`。

#### P1-3 网页 AOE 圆环通常不会出现

**表现**

- 网页实时战场看不到 AOE 圆环。

**原因**

- 查看器后端依赖帧字段 `aoe_radius` 或 `last_aoe_radius`。
- 当前公开帧没有这两个字段。
- 模拟器虽然有 `AOE_SPLASH` 事件，但网页查看器没有消费事件流。

**处理方向**

- 网页视觉事件必须来自模拟器真实事件，不能再依赖猜测字段。

**当前状态**

- 已完成事件桥接：模拟器把真实的 `ATTACK / AOE_SPLASH / DEATH` 事件随展示帧发布。
- AOE 事件携带真实半径和主目标落点，网页与视频共用同一份原始事件语义。

#### P1-4 网页攻击特效和视频不一致

**表现**

- 网页攻击效果只在个别瞬间出现。
- 没有视频里持续约 0.25 秒的抛射物效果。

**原因**

- 视频渲染器有完整事件流和时间戳。
- 网页只有当前帧，目前用 `aim_cd == 0` 近似判断，只在那一帧绘制。

**处理方向**

- 网页查看器消费模拟器真实事件并维护短生命周期缓冲。
- 前端按帧时间过滤，攻击效果保持约 0.25 秒。

**当前状态**

- 已完成：网页不再用 `aim_cd == 0` 或 HP 差值猜测攻击。
- 攻击事件按约 0.25 秒渐隐显示，视频与网页使用同一事件源。

#### P1-5 网页阵亡叉号和 AOE 圆环只存在单帧

**表现**

- 阵亡叉号只是一闪。
- AOE 圆环没有持续 0.3 秒。

**原因**

- 网页通过比较前后帧推导“单位消失”，事件没有历史寿命。
- 没有保存事件起始时间和过期时间。

**处理方向**

- 查看器保存事件时间，前端按生命周期查询。
- 阵亡约 0.6 秒并渐隐，AOE 约 0.3 秒。

**当前状态**

- 已完成：阵亡叉号和 AOE 圆环按真实事件时间持续并渐隐。
- 视频侧对同一炮的多条溅射事件做了去重，避免重复画环。

#### P1-6 `hexToRgba` 是无用实现

**表现**

- 网页中存在 `hexToRgba` 函数，但没有调用。

**原因**

- 视觉层实现期间留下了未使用的颜色转换辅助函数。

**处理方向**

- 删除，避免后续维护者误判它是正式绘制路径。

**当前状态**

- 已完成：已删除。

### P2：已发现但影响较低或需要先确认

#### P2-1 网页 catalog 首包过大

**表现**

- `/api/catalog` 当前会把 815 个兵种图标编码为 data URL。

**影响**

- 首次加载流量和浏览器内存明显增加。
- 不影响正确性，但对开发观测页偏重。

**处理方向**

- 恢复 catalog 只返回稳定 URL。
- 图标按当前模拟实际出现的兵种懒加载或预加载。
- 保留服务端 PNG 缓存。

**当前状态**

- 已完成：catalog 恢复轻量 `icon_url`，图标改为 `/api/icon/<unit_id>` 按需加载。

#### P2-2 视频结尾信息不完整

**当前已有**

- 胜者
- 战斗时长
- 双方剩余兵力
- 是否超时

**缺少**

- 双方总伤害
- 双方总击杀
- 战损资源
- 各兵种损失
- MVP

**处理方向**

- 先确认最终画面需要展示哪些字段。

#### P2-3 关键节点没有慢放

**现状**

- 只有自适应倍速，没有定格或减速。

**候选节点**

- 首次接敌
- 成批死亡
- 最后一击

**处理方向**

- 需确认是否加入，避免打断视频节奏。

#### P2-4 旧播报兼容层仍存在

**现状**

- `Broadcaster`、`brief`、`detailed` 仍被 CLI 调试路径引用。
- 正式群局已经不再使用逐窗口播报。

**处理方向**

- 先确认是否保留兼容层。
- 或在所有消费方迁移完成后彻底删除。

### 明确不做

- 不把开发观测网页改造成视频渲染器。
- 不把自适应倍速引入网页默认播放。
- 不在网页删除 Tick、受阻、无进展、重叠率、转向和绕行等诊断信息。
- 不在回放视频中显示调试指标。
- 不使用抽象几何形状替代兵种 icon。
- 不输出底部归纳型时间带：
  - 首次接敌
  - 首次阵亡
  - 重大伤亡
  - 终局
- 开局图不显示出生位置。

## 第二阶段：当前实现状态

### 已完成

- 移除 HP 环并恢复受伤变暗。
- HUD 兵种构成超过四种时显示 `等 N 种`。
- 网页图标修复、恢复显示并按碰撞体同等半径缩放。
- catalog 轻量化，图标按需加载。
- 模拟器真实战斗事件随帧发布。
- 网页攻击、AOE、阵亡事件按生命周期持续显示。
- 视频侧 AOE 半径和落点补齐，并对同一炮重复溅射去重。

- `uv run pytest tests/games/aoe3_battle -q`
