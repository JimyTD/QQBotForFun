## 1. 通道分工（先定这个，其余都是推论）

| 内容 | 通道 | 理由 |
|---|---|---|
| 报名、面板、死讯、标记播报、投票明细、结算 | **群内** | 本来就是公开信息；群里公开也是这个游戏的乐趣所在 |
| 身份牌、夜间技能询问、投票征求、触发询问（开枪/带人/决斗） | **私聊** | 私密信息；群内问等于公开身份 |
| 标记发言的**输入** | **群内** | 见 §9 决策点 3 |

**机制事实**（已核对源码，不是推测）：

- 群内消息必须 **@机器人** 才会被路由（`message_router.py:90-92`，且 @ 必须在消息**开头或结尾**）。
- **私聊消息 `to_me` 恒为 `True`**（onebot v11 适配器 `bot.py:78-79`），所以私聊回复**不需要 @**，一定路由得到。
- `session.ask(qq, prompt, group_id=None)` 走 whisper；`group_id=群号` 走群内广播并 @ 该玩家（`session.py:291-295`）。
- 玩家回复 `退出` / `quit` / `/quit` / `/q` 时，`session.ask` 抛 `PlayerQuitError`（`session.py:272`）。
- 超时抛 `TimeoutError`；`/结束` 会让等待中的 future 被 cancel → `CancelledError`（必须冒泡）。

## 2. 命令表

命令词 = 游戏名，与深海任务一致。**游戏命令词不能叫「标记」**——那会和标记发言的输入撞车。

| 命令 | 权限 | 生效条件 | 说明 |
|---|---|---|---|
| `@我 静夜标记 [板子]` | 任何人 | 本群**没有**进行中的对局 | 创建报名房间并成为房主；板子默认 `4standard` |
| `@我 加入` | 群成员 | 本群有待开始房间 | 报名 |
| `@我 重复加入` | 房主 | 同上 | 一个 QQ 额外占一个座位（调试用，方便少数人测 4 人局） |
| `@我 离开` | 已报名者 | 同上 | 退出报名 |
| `@我 踢人 3号` | 房主 | 同上 | 按座位号踢人 |
| `@我 板子 6gods` | 房主 | 同上 | 换板子（仅报名阶段） |
| `@我 开始` | 房主 | 同上 | 人数必须**恰好等于**板子人数 |
| `@我 记录` | 本局玩家 | 本群有进行中对局 | 私聊重发「我的记录」 |
| `@我 认输` | 本局玩家 | 同上 | 认输出局（遗物公开）→ `block=False`，见 §5 |
| `@我 结束` | 房主 | 同上 | 已有机制（`/结束`） |
| `@我 帮助` | 任何人 | — | 已有全局帮助 |

**游戏内自由输入（标记发言、座位号、触发选择）不注册命令**，靠 `message_router` 兜底路由给等待者。
这样既不会污染全局命令空间，也避免"没在对局里发 `标记` 被吞掉"。

排期说明：`重复加入` / `踢人` / `板子` 是调试与房主体验，M1c 一起做（照搬深海任务的房间模式）。

## 3. 一次完整对局（4 人标准局，真实文案）

> 4 人标准局角色：1 狼人 + 1 守卫 + 1 女巫 + 1 平民；胜负条件：屠边。

### 3.1 报名

```
[群] @小明  @我 静夜标记
[bot] 🌙 静夜标记 · 报名中
      板子：4 人标准（狼人×1 · 守卫×1 · 女巫×1 · 平民×1 · 屠边）
      人数：1/4　还差 3 人
      报名：@我 加入　房主开局：@我 开始　换板子：@我 板子 6gods

[群] @小红  @我 加入
[bot] ✅ 小红 加入（2/4）
...
[群] @小明  @我 开始
```

### 3.2 开局：群内面板 + 私聊身份牌

```
[bot] 🌙 静夜标记 · 开局
      板子：4 人标准（狼人×1 · 守卫×1 · 女巫×1 · 平民×1）
      狼人胜利条件：屠边（杀光神职 或 杀光平民）
      随身物品：月光石、天平徽章（存活时只知道类型，出局后公开内容）

      1号 小明✅　2号 小红✅　3号 小刚✅　4号 小美✅

      📩 身份牌已私聊发出，请查看私聊。
      🌙 夜里按私聊提示行动；☀️ 白天在群里按提示标记发言。
```

私聊（每个玩家各一条，下面以狼人和女巫为例）：

```
[私聊 小明] 🎭 你的身份牌
           座位：1号 小明
           身份：狼人（狼人阵营）
           同伴：（无，你独自一人）
           能力：夜里与同伴共同选择袭击目标；白天要伪装成好人。允许自刀。
           随身物品：月光石: 0（内容未知，出局后公开）
           狼人胜利条件：屠边（杀光神职 或 杀光平民）

           💡 夜里按私聊提示行动；白天在群里按提示标记发言（@我 记录 可随时查看你的记录）

[私聊 小美] …身份：女巫（好人阵营）
           能力：解药、毒药各一瓶；首夜可以自救，之后不能。同一晚只能用一瓶药。
```

### 3.3 第 1 夜（逐角色私聊，不打扰无夜间能力的角色）

```
[bot] 🌙 第 1 夜 —— 天黑请闭眼
      1号 小明✅　2号 小红✅　3号 小刚✅　4号 小美✅
```

守卫 / 狼人 / 女巫各收到一条私聊（顺序：守卫 → 狼人 → 女巫 → 预言家 → 守墓人）：

```
[私聊 小刚] 🛡 请选择今晚的守护目标（不可与上一晚相同）
           （3号 小刚）

           可选：1号 小明、2号 小红、4号 小美、3号 小刚

           回复座位号（如 3）

           ⏳ 请在 60 秒内私聊回复

[私聊 小明] 🐺 请选择今晚的袭击目标（可以自刀）
           （1号 小明）
           …
```

> 狼人合议：多狼局**逐狼私聊**，第二只狼的提示里会多一行
> `🐺 队友当前意向：2号 小红`（QQ 没有实时同步，用这个等价替代）。

女巫会额外看到**私有信息**（今夜被刀的是谁）：

```
[私聊 小美] 🧪 女巫用药
           （4号 小美）

           🩸 今晚被袭击的是：2号 小红
           解药：未使用　毒药：未使用

           回复：
             救　　　　使用解药救被袭击者
             毒 3　　　 使用毒药毒 3 号
             不用　　　 今晚不使用药物
```

平民、猎人、白痴、骑士**整夜收不到任何私聊**（不打扰）。

### 3.4 死讯（只说谁死了，不说为什么）

```
[bot] ☀️ 第 1 夜结算
      平安夜，无人出局。
```

或：

```
[bot] ☀️ 第 1 夜结算
      ⚠️ 2号 小红 出局
      　遗物：月光石: 1
```

> **刻意的信息等价**：被守住的夜、被解药救的夜、狼人空刀的夜，公告必须**完全一样**。
> 死因绝不公布（`被毒死` / `同守同救` 都会反向暴露女巫与守卫的行为）。

### 3.5 触发链（只有相关角色会被私聊）

- **猎人**（非被毒死）：私聊「开枪 / 跳过」
- **白狼王**（被放逐）：私聊「带人 / 跳过」
- **骑士**（每天问一次，直到用过）：私聊「决斗 X / 跳过」

**跳过不在群里公告**（见 §6 泄露审查 2）。

### 3.6 标记发言（群内，按座位顺序）

```
[bot] ☀️ 天亮了 —— 标记发言（按座位顺序，轮流发言）
      1号 小明✅　2号 小红✅　3号 小刚✅　4号 小美✅

[bot] 📝 1号 小明 轮到你了，请标记发言
      身份声明（给自己）：神职、好人、女巫、守卫、平民
      评价标记（给其他存活玩家）：神职、好人、女巫、守卫、平民、狼人
      可选理由：直觉判断、投票分析、标记分析、日志推理、查验结论、用药结果

      格式：@我 标记 <身份> <理由> | <座位> <评价身份> <理由> | ...
      例：@我 标记 好人 直觉判断 | 3号 狼人 标记分析 | 5号 好人 直觉判断
      （理由可省略，默认「直觉判断」；只发「@我 标记」可进入逐步引导）

      存活玩家：2号 小红、3号 小刚、4号 小美

      ⏳ 请在 120 秒内 @我 回复

[群] @小明  @我 标记 好人 直觉判断 | 2号 狼人 标记分析 | 3号 好人 直觉判断
[bot] 📌 1号 小明 声明身份：好人（直觉判断）
      　 → 认为 2号 小红 是 狼人（标记分析）
      　 → 认为 3号 小刚 是 好人（直觉判断）
```

输入写错时**一次列全所有问题**再重问（不逐个来回）：

```
[bot] ⚠️ 输入有问题，请重新发送：
      · 身份声明段多了内容：「好人」。评价标记要用「|」分隔，例如：标记 好人 直觉判断 | 3号 狼人 标记分析
      · 9 号没有座位
      <原始提示原样重发>
```

只发 `@我 标记` → 进入**逐步引导**（身份 → 理由 → 每个目标：目标 → 身份 → 理由），
与一行式产出**完全相同的状态**（能力等价，不会因为用引导就少给理由）。

### 3.7 投票（私聊征求 + 群内回执 + 收齐统一公布）

```
[bot] 🗳 投票放逐（4 人投票，收齐后统一公布）

[私聊每人] 🗳 请选择要放逐的玩家
           （2号 小红）
           可选：1号 小明、3号 小刚、4号 小美
           回复座位号（如 3）

[bot] ✅ 1号 小明 已投票
      ✅ 2号 小红 已投票
      ✅ 3号 小刚 已投票
      ✅ 4号 小美 已投票

[bot] 🗳 第 1 轮投票结果
      　1号 小明 → 2号 小红
      　2号 小红 → 3号 小刚
      　3号 小刚 → 2号 小红
      　4号 小美 → 2号 小红
      结果：2号 小红 得票最高，将被放逐

[bot] ⚖️ 2号 小红 被放逐出局
      　遗物：月光石: 1
```

平票时：`结果：平票，无人出局`（源项目同口径）。
白痴被放逐时：`🤪 X 是【白痴】，本次放逐免疫（身份公开，此后失去投票权但仍可标记发言）`。

### 3.8 结算

```
[bot] 🏆 游戏结束 —— 好人阵营胜利
      （所有狼人已出局）

      全部身份：
      　1号 小明 — 平民
      　2号 小红 — 狼人（出局）
      　3号 小刚 — 守卫
      　4号 小美 — 女巫
```

## 4. 异常与中断矩阵

| 场景 | 表现 | 是否泄露信息 |
|---|---|---|
| 玩家超时（**公开**动作：标记、投票） | 群内点名 `⏰ X 超时未响应，已按默认处理` + 兜底继续 | 否（人人都会做这些动作） |
| 玩家超时（**私密**动作：夜间/触发） | **只在私聊告知本人**；群内不发点名 | 是 → 所以不公开（§6） |
| 玩家回 `退出` / `quit` | 视为**认输**：出局 + 遗物公开 + 立即判胜负 | 否（遗物本来就公开） |
| 玩家发 `@我 认输` | 同上 | 否 |
| 私聊不可达（未加好友）·**开局时** | 点名劝退整局，不发身份牌、不进入夜晚 | — |
| 私聊不可达 · **对局中** | 该回合走兜底；群内提示 `⚠️ 无法私聊 X，本回合按默认处理` | ⚠️ 轻微（暴露 X 在夜间被问过）→ 见 §6 |
| 房主 `@我 结束` | 群内 `🏳 本局静夜标记已结束（主动终止）` + 座位表 | — |
| 玩家中途退群/被踢 | M1c 不处理（靠超时兜底）；M5 加离群检测 | — |
| 全员离线 | 每个动作都有超时 → **不可能永久卡住** | — |

**兜底矩阵**（与源项目 `submitDisconnectedFallback` 同口径）：

| 动作 | 超时兜底 |
|---|---|
| 守卫 / 预言家 / 狼人 / 守墓人 | 从合法目标里随机选一个 |
| 女巫 | **不使用任何药物**（源项目明确如此，避免误用） |
| 标记 | 声明「好人」+ 直觉判断 + 按顺序取 N 个存活玩家 |
| 投票 | 候选里第一个不是自己的（等于弃票） |
| 猎人 / 白狼王 / 骑士 | 跳过 |
| 无合法目标（残局） | 直接跳过并推进——**绝不原地等待** |

## 5. 两个必须写进代码的交互细节

1. **`@我 认输` 必须 `block=False`**。否则消息被命令消费掉，等待中的 `ask` 收不到，
   玩家认输后还要干等一个超时。`block=False` 让它同时到达等待者，`_ask` 检测到"该玩家已出局"
   就立刻返回，兜底接管。
2. **群内提示必须把 `@我` 放在消息开头或结尾**（适配器只认首尾 @）。
   我们的格式示例里 `@我` 在开头，是合规的；后续改文案时不能把它挪到中间。

## 6. 信息泄露审查（**本轮发现 2 处必须修**）

这个游戏的乐趣全在"谁在演谁"，所以信息泄露比规则 bug 更致命。逐条审：

### 泄露 1【必须修】：夜间超时会公开点名

当前 `game.py::_ask` 不论通道一律群内广播 `⏰ X 超时未响应`。
夜间被问到的角色只有**守卫/狼人/女巫/预言家/守墓人**——群内一句"X 超时"等于告诉所有人
**X 是这五类之一**。12 人局里这是致命信息。

**修法**：给 `_ask` 加 `sensitive: bool`。私密动作（夜间技能、触发链）超时/私聊失败时
**只私聊告知本人**，群内不点名（可发一条无人称的 `⏰ 有人未响应，已按默认继续`，也可以什么都不发）。
标记与投票是公开动作，保持群内点名。

### 泄露 2【必须修】：技能"跳过"被公开

当前 `_resolve_trigger` / `_run_knight` 在玩家选择跳过时群内广播
`🔫 X 选择不开枪`。这等于**公开 X 是猎人**（白狼王、骑士同理）。

**修法**：跳过只在私聊确认本人，群内**不发**。开枪/带人/决斗成功才公开——
而且那时公开是**设计预期**（源项目的公开死因里就有「猎人射杀」「白狼王带走」「决斗」）。

### 已确认不泄露（不用改）

- 夜间死因统一不公布 → 平安夜 / 被守 / 被救 / 空刀 在公告上完全等价 ✅
- 遗物公开 → 源项目设计如此 ✅
- 投票明细公开 → 源项目设计如此（这是游戏的公开记录） ✅
- 白痴免疫公开身份 → 机制使然（放逐失败必须有解释） ✅
- `✅ X 已投票` 回执 → 投票权是公开信息，不泄露身份 ✅

## 7. 消息量估算（决定"一局多久"的实感）

4 人局、跑 2 轮：

| 阶段 | 群内 | 私聊 |
|---|---|---|
| 报名 | 1 + 2/人 | 0 |
| 开局 | 1 | 4（身份牌） |
| 每轮夜晚 | 1（天黑）+ 1（死讯） | 2~4（有夜间角色的人各 1） |
| 每轮标记 | 4（提示）+ 4（播报） | 0 |
| 每轮投票 | 1 + 4（回执）+ 1（明细）+ 1（放逐） | 4（征求） |
| 结算 | 1 | 0 |
| **合计** | **约 40 条** | **约 20 条** |

按每条 5~10 秒的响应节奏，**一局 15~25 分钟**，比 web 版（10~15 分钟）慢。
这是"QQ 版体感"的核心数字，也是我认为最需要真机实测的地方。

## 8. CLI 侧（同一份文案，允许的差异）

| 项 | Bot | CLI | 依据 |
|---|---|---|---|
| 提示里的 `@我` | 有（群内必须 @） | **无**（`render_mark_prompt(at_prefix=False)`） | `docs/13` 允许的「@提及」差异 |
| 私聊提示 | whisper | 直接打印，带座位前缀 | `docs/13` 允许的「私聊」差异 |
| 多人模拟 | 真实多人 | 单终端多视角（热座） | 同上 |
| 超时 | 真实计时 | 不模拟（交互式） | 同上 |
| 平台中断 | `/结束` | `quit` | 同上 |

CLI 与 Bot 共用：`syntax.py`（解析 + 输入提示）、`views.py`（公告/面板/记录）、`engine/*`（全部规则）。
CLI 只额外负责"把谁该说话"轮流呈现给同一个终端。

| # | 决策 | 我的建议 |

| 5 | 结算后是否撤回私聊提示 | **不撤回**，身份牌与记录留着便于复盘（深海撤回是因为手牌会变）。M5 若要可加开关 |
| 6 | 是否公开个人奖励明细 | **不公开**，只在群内公布胜负与身份 |

> 决策 3 的补充：如果你更看重"零门槛"，可以改成**私聊收集 + 群内播报**——
> 玩家不用记 @，但每轮多 4 条私聊。我倾向先按群内做，真机跑几局再决定要不要改。
