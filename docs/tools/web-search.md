# 🔍 AI / 查资料（tools/ask_ai）

- **Status**: v1.1
- **Last Updated**: 2026-08-13
- **Type**: 小工具（tool），**非游戏**

---

## 1. 定位

`ai` / `查资料` 起手，**后面整句话**按群聊助手来答：先取网上材料，再写成能直接用的回答。入口不改，改的是返回内容。

```
用户: @机器人 ai 量子力学是什么
  ↓
百科（适合才查） + 搜狗 并行
  ↓
抓前 2 条结果页正文
  ↓
glm-4-flash 依据材料成文（200–800 字，先结论后展开）
  ↓
回复（带来源域名；未联网会标明）
```

搜狗仍是国内机房能打通的网页搜索。百科不再一命中就锁死整次回答。

---

## 2. 触发

- `@机器人 ai <问题>`
- `@机器人 查资料 <问题>`
- `@机器人 搜索 / 搜一下 / 问AI / search <问题>`

仅心算、打招呼、问机器人自己时跳过搜索。
