# 深海任务

`deep_sea_mission` 是《The Crew: Mission Deep Sea》风格的合作吃墩游戏。

- **任务难度**：`@机器人 深海任务 <难度>`，随机抽任务卡凑到指定总分。
- **战役**：`@机器人 深海战役`，官方 32 关 + Epilogue；细节见 [deep-sea-mission-campaign.md](deep-sea-mission-campaign.md)。
- **规则原文摘要**：[`docs/new-game.md`](../new-game.md)。
- **任务自动判定**：`src/plugins/games/deep_sea_mission/rules.py`。

官方桌面规则：任务条件满足就翻面；**全部翻完即可停，不必打完剩余墩**。失败则任一任务破产即负。

---

## 开局

1. `@机器人 深海任务 <难度>`（例如 8）创建房间，或 `@机器人 深海战役` 读本群进度。
2. `@机器人 加入` 报名；单账号调试可用 `@机器人 重复加入`。
3. 3–5 人后房主 `@机器人 开始` / `@机器人 发牌`。
4. 机器人私聊手牌；任一私聊失败则本局结束。

队长是持有 `潜艇4` 的玩家。任务选择：`@机器人 选 2`；任务少于人数时可 `@机器人 过`。

## 出牌

```text
@机器人 出 蓝4
@机器人 蓝4
@机器人 出 潜艇2
```

简写：`b4`、`y7`、`g6`、`p3`、`s2`。校验轮次、手牌、跟花；潜艇是将牌。

3 人局 40 张牌会有一人多 1 张：有人手牌打光即出牌结束，多的那张不打。「最后一墩」= 实际打出的最后一墩。

## 结算（现状）

任务按牌局记录自动判定完成 / 失败。出牌结束后进入核对：`@机器人 胜利` / `@机器人 失败`。

出牌阶段的「胜利」是调试后门，不参与提前胜负设计。

## 任务判定与提前胜负

提前判的不是「猜后面打什么」，而是：**公开信息是否已经把某张任务锁死为完成或失败**。全部任务锁死完成 → 整局可以提前胜；任一任务锁死失败 → 可以提前负。

### 信息边界

| 可以用（公开） | 不可以用（泄牌） |
|---|---|
| 已打完的墩、赢家、墩上出现过的牌 | 各人手牌里还有什么 |
| 各人已赢墩数 | 跟花后谁还能吃到某张未出场牌 |
| 还剩几墩（人手牌张数的最小值，人人可见） | 用私牌推「他后面吃不到 / 必须垫掉」 |
| 未出场牌的**数量**（总牌 − 已出场） | |

未出场粉牌还剩 3 张、就算领取者全吃到黄仍更多——这是公开计数，**应该做**。那张粉 8 在队友手里、他会垫掉——这是偷看，**不要做**。

先前把「剩余墩数锁死 / 已出场牌锁死 / 无任务关」写成「明确不做」，是拆工作量，不是这些结论错误。

### 代码现状

判定在 `rules.py`：每墩后用公开信息锁死完成/失败，不再用 `FINAL_ONLY` 把任务拖到终局。全部锁死完成则自动收局，剩余墩不打。失败只提示，可继续复盘或 `@我 失败`。

### 1. 达成即完成

条件一旦满足就不可能被后面的墩撤销。中途翻面；本局若全是这类，最后一张翻面即可提前胜。

| 形态 | 编号 |
|---|---|
| 赢一墩带某性质 | T007–T015、T046–T050、T058–T059、T093–T094 |
| 赢指定牌 | T016–T019、T027–T035、T054 |
| 至少 N / 全部（全套上限就是 N） | T020–T024、T038–T039、T044–T045 |
| 至少连续 N 墩、赢第一墩 | T085、T086、T079 |

官方有一句 “Exactly or At least … determined at the end”。「恰好」必须等或靠锁死；「至少」凑够就不可能再少，按中途完成。

未达成时：出牌结束仍未达成 → 失败。中途一般不因「还没凑够」判负（除非剩余公开计数已经够不着，见第 3 节）。

### 2. 窗口关闭即可定

只约束前 N 墩。第 N 墩打完，成败已经确定，不必再等后面。

| 任务 | 何时定 |
|---|---|
| T079 赢第一墩 | 第 1 墩结束（已按第 1 类处理） |
| T077 / T078 赢前三 / 前两墩 | 第 3 / 2 墩结束：齐了完成，缺了失败 |
| T080 第一墩和最后一墩 | 第 1 墩若没赢就失败；成功仍要等最后一墩 |
| T071 / T072 / T073 不要前 N 墩 | 前 N 墩里吃到就失败；第 N 墩结束还没吃到 → 完成 |

T079（赢第一墩）与这两条同一窗口模型。

### 3. 禁止 / 恰好 / 比较 / 预测：靠锁死，不是「只能终局」

中途默认 pending。**锁死完成或锁死失败时就该改状态**，不必等打光。

下面 `R` = 剩余墩数。未出场某类牌的张数 = 该类总数 − 已出场张数（来自 `trick_history`）。

**比较墩数（T001–T006）**

只看已赢墩数和 `R`，不看手牌。

- T001 比其他任意一人都多：完成 `owner > max(他人) + R`；失败 `owner + R ≤ max(他人)`。
- T002 比其他合计还多：完成 `owner > sum(他人) + R`；失败 `owner + R ≤ sum(他人)`。
- T003 比其他任意一人都少：完成 `owner + R < min(他人)`；失败 `owner ≥ 某人`（墩数不会减少）。
- T004 / T005 相对队长：同上，只比队长。
- T006 与队长相同：`R = 0` 时看是否相等；`|owner − 队长| > R` 时失败（落后方追不上）。`R > 0` 且已经相等 → 尚未锁死（后面谁吃墩都会打破）。

**禁止类（不要赢 / 不要开墩 / 不要连墩）**

- 一违约就失败（T043、T057、T060–T075）。
- 锁死完成：约束窗口里已经不可能再违约。例如「不赢任何粉牌」且 9 张粉全部出场、领取者一张都没吃到；「不要前四墩」且第 4 墩已过（第 2 类）；「不要任何墩」且 `owner=0` 且 `R=0`，或 `R>0` 但……不偷看手牌时，只要还有墩，领取者仍可能吃到，T074 提前完成只在 `R=0`。
- 开墩颜色（T060 / T061）：不偷看则无法证明后面不会用禁色开墩，提前完成只在 `R=0`；提前失败一开出禁色即可。

**恰好（张数 / 墩数 / 连续）**

- 已超额 → 失败（恰好 3 张 6 却吃了第 4 张；恰好 1 墩却吃了第 2 墩）。
- 加上全部剩余可能仍够不着 → 失败（`owner墩 + R < 目标`；未出场的 6 不够凑到「恰好 3」且已少于 3）。
- 已经刚好，且多吃会破坏的那种「剩余机会」已经没了 → 完成。例如恰好 3 张 6：自己已有 3 张，第 4 张 6 已在别人墩里出场。自己已有 3 张而第 4 张 6 尚未出场 → **不能**完成（领取者仍可能再吃到）；也不要去看那张 6 在谁手里。
- T088 / T089「恰好连续 N 墩」：已经出现更长连续 → 失败；已经出现过长度为 N 的连续，且后面不可能再连出更长或另一段（通常要 `R` 不够再连，或已断开且 `R=0`）→ 完成。未出现过且 `owner + R` 不够连出 N → 失败。

**预测 X 墩（T090 / T091）**

- 已赢 `> X` → 失败。
- `已赢 + R < X` → 失败。
- 已赢 `= X` 且 `R = 0` → 完成。
- 已赢 `= X` 且 `R > 0` → 尚未锁死（不偷看则后面仍可能再吃墩）。

**花色张数比较（T092 / T095 / T096）**

用已赢张数 + 未出场张数做最坏 / 最好公开上界，与墩数比较同一思路。T092 两边都必须 `> 0`：有一边已确定为 0（该色 9 张全部出场且领取者 0 张）→ 失败。

### 4. 绑死最后一墩

不偷看手牌时，成功必须看到最后一墩；失败可以更早。

| 任务 | 提前完成 | 提前失败 |
|---|---|---|
| T036 最后一墩赢绿 2 | 否 | 绿 2 已在非最后墩被任何人吃走；或绿 2 是 3 人局那张不打的剩牌（出牌结束时仍未出场） |
| T076 赢最后一墩 | 否 | 无（只能终局看是不是领取者赢） |
| T080 第一墩和最后一墩 | 否 | 第一墩没赢 |
| T081 只赢最后一墩 | 否 | 已经赢过非最后墩 |
| T082 只赢第一墩 | 否（`R>0` 时后面仍可能再吃） | 第一墩没赢；或已经赢了第 2 墩及以后 |

### 5. 战役无任务关（M8 / M12 / M21 / M23 / M27）

没有任务卡，约束贯穿整副牌。同样只用公开信息锁死。

| 关 | 提前负 | 提前胜 |
|---|---|---|
| M8 不得有人比别人多赢 2 张 9 | 已有人 9 的张数差 `≥ 2` | 未出场的 9 按最坏分配也拉不开 `≥ 2` |
| M21 对 1 同样 | 同 M8 | 同 M8 |
| M12 不得用粉或潜艇开墩 | 一开出就负 | 不偷看则只有 `R=0` 且从未违约 |
| M23 首墩赢家须始终领先墩数 | 被追上（并列也算破） | 领先已满足「比较墩数」那种 `> max(他人)+R` |
| M27 黄 5 须为最后一墩最后一张 | 黄 5 已经打出且不是这个位置 | 否 |
