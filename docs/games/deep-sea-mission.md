# 深海任务

`deep_sea_mission` 是《The Crew: Mission Deep Sea》风格的合作吃墩游戏框架。

## 开局

1. 房主在群里发送 `@机器人 深海任务 <难度>`，例如 `@机器人 深海任务 8`。
2. 玩家发送 `@机器人 加入` 报名。
3. 单账号调试时，可以发送 `@机器人 重复加入` 添加一个由自己控制的临时座位。
4. 满 3-5 个座位后，房主发送 `@机器人 开始` 或 `@机器人 发牌`。
5. 机器人私聊每位玩家手牌；若任何私聊失败，本局立即结束。

## 任务

机器人会按当前人数读取每张任务卡对应的难度，随机抽取任务，使总难度等于开局指定值。任务卡全部以中文录入，但当前不做自动判定。

队长从持有 `潜艇4` 的玩家开始。任务选择阶段，当前玩家发送：

```text
@机器人 选 2
```

任务少于玩家时，可以发送：

```text
@机器人 过
```

## 出牌

出牌阶段，当前玩家在群里发送：

```text
@机器人 出 蓝4
@机器人 蓝4
@机器人 出 潜艇2
```

支持简写：`b4`、`y7`、`g6`、`p3`、`s2`。

机器人负责校验是否轮到该玩家、是否持有该牌、是否必须跟首牌花色。潜艇是将牌。

## 手动结算

玩家自己确认任务是否完成：

```text
@机器人 完成 2
@机器人 撤销完成 2
```

任务领取者或房主可以宣告胜利：

```text
@机器人 胜利
```

任意玩家可以宣告失败：

```text
@机器人 失败
```

胜利时所有参与玩家获得奖励。
