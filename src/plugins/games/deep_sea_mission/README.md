# 深海任务

合作吃墩桌游框架，规则来源见 `docs/new-game.md`。

## 当前实现

- 3-5 人报名房间：`@我 深海任务 8`、`@我 加入`、`@我 重复加入`、房主 `@我 开始`/`@我 发牌`
- 单账号调试座位：重复加入会创建由同一 QQ 控制的临时座位
- 私聊发手牌；任一玩家私聊失败会直接结束本局
- 队长为持有 `潜艇4` 的玩家
- 按人数和目标难度随机抽任务卡
- 从队长开始轮流选择任务：`@我 选 2`
- 群内 @ 机器人出牌：`@我 出 蓝4` / `@我 蓝4`
- 校验轮次、手牌、跟花色、潜艇将牌，并结算每墩赢家
- 任务根据牌局记录自动判定完成/失败
- 公开预测任务需要领取者在群里输入：`@我 预测 1 3`
- 秘密预测任务需要领取者私聊输入：`预测 1 3`
- 玩家人工宣告 `@我 胜利` / `@我 失败`
- 胜利时所有玩家获得奖励
