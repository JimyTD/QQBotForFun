# 深海任务

合作吃墩桌游框架，规则来源见 `docs/new-game.md`。

## 当前实现

- 3-5 人报名房间：`@我 深海任务 8`、`@我 加入`、`@我 重复加入`、房主 `@我 开始`/`@我 发牌`
- 单账号调试座位：重复加入会创建由同一 QQ 控制的临时座位
- 私聊发手牌；任一玩家私聊失败会直接结束本局
- 队长为持有 `潜艇4` 的玩家
- 按人数和目标难度随机抽任务卡
- 从队长开始轮流选择任务：`@我 选 2`
- 群内 @ 机器人出牌：`@我 出 蓝4` / `@我 蓝4`
- 校验轮次、手牌、跟花色、潜艇将牌，并结算每墩赢家
- 任务由玩家人工确认：`@我 完成 2`、`@我 撤销完成 2`
- 玩家人工宣告 `@我 胜利` / `@我 失败`
- 胜利时所有玩家获得奖励

## 战役模式（`@我 深海战役`）

- 官方 32 关 + Epilogue，进度存 `group_config`，通关自动 +1，中途不存档
- 6 类特殊符号：❓ Currents（声呐不公开标记）、-2 Rapture（全队共享声呐）、🔴 Unfamiliar（抽颜色卡定声呐）、🕒 限时（不计时走替代规则）、🐙 自由选任务、⚓ 求救传牌
- 任务分配规则：一人/两人自荐包揽、队长包揽、最难任务给队长、队长不接任务
- 5 个无难度关（8/12/21/23/27）特殊胜利约束，宣告胜利时校验
- M32 固定 4 张任务卡，不抽卡
- 求救信号：选任务阶段 `@我 求救`，每人 `@我 传 蓝4` 传 1 张给左邻（禁传潜艇）
